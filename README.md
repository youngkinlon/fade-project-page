# FADE project page

Static project website for **FADE: Fractional Anomalous Dynamics Extrapolation for Training-Free Diffusion Transformers Acceleration** (NeurIPS 2026).

Open `index.html` in a browser, or run `python -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Images

The page currently uses these PNG files. Replace any of them at the same path to update the website:

| File | Suggested content |
| --- | --- |
| `static/images/teaser.png` | Wide overview / teaser graphic |
| `static/images/dynamics.png` | Anomalous dynamics evidence (paper Figure 1) |
| `static/images/method.png` | FADE framework (paper Figure 2) |
| `static/images/flux-comparison.png` | Full FLUX.1 qualitative comparison figure from the paper |

Select the FLUX.1 comparison image on the website to open it at its original size.

The website embeds no videos. The Paper buttons open the [NeurIPS paper page](https://neurips.cc/virtual/2026/poster/149903). A PDF is not bundled with this website.

Edit author spelling, citation, descriptions, or links directly in `index.html`; edit the visual style in `static/css/index.css`. The BibTeX copy button and image-slot behavior live in `static/js/index.js`.
